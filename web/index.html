Add GitHub token

Without a token GitHub allows 60 API calls per hour; a lookup takes about 5–30. A token raises that to 5,000. Use a fine-grained token with no permissions (public data needs none), not your gh auth token. It is kept for this tab only and is only sent to api.github.com.
